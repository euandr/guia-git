GIT / CONTROLE DE VERSÃO

Entenda o Git.

Git é um sistema de controle de versão distribuído. Ele permite registrar as alterações feitas em um projeto ao longo do tempo, facilitando o trabalho em equipe e permitindo recuperar versões anteriores dos arquivos.

bash — gitbase ~/projeto

$ git --version

git version 2.51.0


$ git init

Initialized empty Git repository

Com o Git você pode:

01

Salvar diferentes versões do seu projeto e acompanhar sua evolução ao longo do desenvolvimento.

02

Ver quem realizou cada alteração e acompanhe as mudanças feitas nos arquivos.

03

Recupere versões anteriores e desfaça alterações quando algo não sair como esperado.

04

Crie ramificações para desenvolver novas funcionalidades separadamente sem interromper no arquivo principal.

05

Una alterações feitas por diferentes pessoas no mesmo projeto para criar um projeto completo.

06

Trabalhe localmente sem precisar estar conectado à internet o tempo todo.

GIT ≠ GITHUB

Eles trabalham juntos, mas são diferentes.

Git é diferente de Git Hub, eles são frequentemente confundidos, mas possuem funções diferentes dentro do desenvolvimento de software.

GIT

Controle de versão

Git é a ferramenta responsável por controlar as versões e registrar o histórico do seu projeto.

GITHUB

Plataforma de colaboração

GitHub é uma plataforma que permite hospedar repositórios Git e colaborar com outras pessoas.

🛠️ CONFIGURAÇÃO

Configure o Git antes de começar.

Depois de instalar o Git, é recomendado configurar seu nome e e-mail. Essas informações serão utilizadas para identificar quem realizou cada commit.

GIT CONFIG

USER INFORMATION

$ git config --global user.name "Seu Nome"

$ git config --global user.email "seu@email.com"

VERIFICAR CONFIGURAÇÕES

$ git config --list

Esse comando exibe as configurações atuais do Git, permitindo conferir se seu nome e e-mail foram configurados corretamente.

📁 REPOSITÓRIO

Comece seu projeto

Para começar a controlar um projeto com Git, entre na pasta do projeto e execute o comando git init.

CREATE REPOSITORY

LOCAL PROJECT

$ git init

Initialized empty Git repository

O comando git init cria um repositório Git na pasta atual, permitindo que o Git comece a acompanhar as alterações realizadas no projeto.
