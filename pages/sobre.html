Sobre O GitBase

O GitBase é uma plataforma educacional criada para tornar o aprendizado de Git e GitHub mais simples, visual e acessível.

Aqui você encontra explicações, exemplos e guias práticos para entender desde os conceitos básicos de versionamento até o uso das principais ferramentas do Git e GitHub.

Nosso objetivo é ajudar quem está começando a programar a desenvolver confiança para trabalhar com seus próprios projetos e colaborar com outras pessoas.
