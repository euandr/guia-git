Entenda a diferença básica

A união perfeita entre versionamento local e hospedagem em nuvem.

Git (Local)

Sistema de controle de versão distribuído. Roda direto na sua máquina, rastreando o histórico do seu código e salvando os estados locais (commits).

git push git pull

GitHub (Nuvem)

Plataforma online onde você hospeda seus repositórios Git na nuvem, permitindo colaboração em equipe, revisão de código e backup seguro.

Aprenda fazendo

Clique em um comando para entender exatamente a sua função na prática.

git status

Exibe o estado atual do diretório de trabalho e da área de preparação (staging area). Mostra quais arquivos foram modificados, salvos ou ainda não estão sendo rastreados pelo Git.

$ git status
# On branch main
# Untracked files: index.html
