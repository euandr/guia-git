# GitBase

O **GitBase** é um projeto desenvolvido como atividade acadêmica da disciplina de Programação Web, com o objetivo de apresentar conceitos e funcionalidades do Git e GitHub de forma simples e visual.

## 📚 Conteúdo

O site apresenta conteúdos sobre:

- **Git:** conceitos, comandos e controle de versões.
- **GitHub:** repositórios, colaboração e funcionalidades da plataforma.
- **Guias:** materiais de apoio para facilitar o aprendizado.
- **Sobre:** informações sobre o projeto.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
